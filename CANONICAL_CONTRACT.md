# community-jobs canonical contract

Scratch outputs of community requests and K.O.R.A. executor jobs (a handle-name list, remediation notes, a patch destined for `api.handle.me`, executor logs). It is not a source of truth.

1. A patch or snippet kept here is never applied from here; it is applied in its owning repository.
2. No file here claims chain accuracy; the handle-name list is a snapshot of an API snapshot, and the owning API is authoritative.
3. No keys, tokens, mnemonics, `.env` values or credentialed URLs are kept here, including in executor logs.
